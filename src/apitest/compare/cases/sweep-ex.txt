# that each returns. Files and windows, the shell, quickfix, tags, help,
# sessions, spelling, autocommands, syntax, folds, and about four hundred

#

# run outside restricted mode, so ":!ls" and its relatives do run a program.
# ":sh" and ":shell" are left out: they start a shell and wait for it.
# ":cq" is known not to come back -- it exits the process (TODO.md).
